# TaskFlow-Project
Веб-приложение для управления задачами, трекинга привычек и отслеживания личного прогресса.

## Команда проекта
* **Frontend-разработка:** 1 разработчик
* **Backend-разработка:** 2 бэкендера

##  Стек технологий
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** Python, FastAPI
* **Инструменты:** Git / GitHub, VS Code, Live Server, Maven, JUnit
